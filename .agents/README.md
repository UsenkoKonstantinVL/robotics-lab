# AI agent context

This directory contains project-specific context for AI-assisted development.
It must not contain credentials, machine-local state, generated files, or chat
transcripts.

- `instructions.md` defines the working rules for changes to this repository.
- `skills/` contains reusable workflows that agents can discover in this
  repository.
- Future focused context may be added here when it is not appropriate for the
  public developer documentation.
