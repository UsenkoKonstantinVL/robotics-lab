# Examples

Examples are small applications that demonstrate how to use the framework and
its external dependencies. They are not framework APIs and may favor clarity
over general-purpose abstractions.

- [`mujoco_viewer`](mujoco_viewer/README.md) runs an MJCF model or scene in
  MuJoCo's passive viewer and applies DDS control commands.
- [`cyclonedds`](cyclonedds/README.md) demonstrates publish/subscribe messaging
  between C++ and Python processes.
